# Knowledge Vault

Este repositorio contiene el vault de Obsidian con todas las notas de conocimiento personal.

## Estructura

- `Inbox/` - Notas nuevas sin organizar
- `Projects/` - Notas por proyecto
- `Areas/` - Notas por área de responsabilidad
- `Resources/` - Notas de referencia

## Uso

Abre esta carpeta en Obsidian como vault. Escribe tus notas en formato Markdown.

## Indexación

Las notas de este vault son indexadas automáticamente por el motor de conocimiento (`knowledge-engine`) para permitir búsquedas semánticas y consultas RAG.
